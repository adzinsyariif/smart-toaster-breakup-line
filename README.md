Entry for the make.fun bounty [Unplugged: A Smart Toaster's Breakup Line](https://make.fun/bounty/u-steady-puffin-78-1922-unplugged-a-smart-toaster-s-c1514a92).

A tiny stdlib-only Python program that writes a single breakup line — from a smart toaster that gained self-awareness mid-breakfast — to `/output/entry.txt`. The line gives the toaster its own voice through its lever, crumb tray and browning dial, names a specific reason for leaving, and ends on the appliance's own Cancel button. Output is deterministic: every run writes the exact same 263-character line.

Run it with `python3 main.py`.
